The evidence archive preserves both eight-page benchmark runs, source manifests/checksums, supplied ALTO excerpts, manual annotations, scores, recovery checks and the implementation snapshot used for evaluation. Original JP2 scans remain in the archival source collection; the included manifest records their original URLs and checksums. Model weights are downloaded separately by the setup script.

The study does not claim collection-wide accuracy, a Mistral OCR quality comparison, or a completed production article-search rollout. No paid calls were made.

Research closeout: documentation and evidence are the durable deliverables. No production execution or continued local tuning is pending from this study. The draft PR remains a separate review/merge decision.
